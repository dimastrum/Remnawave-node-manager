# Remnawave Node Manager

Установка, восстановление и аудит RemnaNode — из одного терминального меню.

**Ubuntu 24.04 LTS** · **Bash** · **v0.2.9 Beta**

## 🚀 Быстрый запуск

Откройте терминал сервера от **root** и выполните:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/dimastrum/Remnawave-node-manager/main/install-v0.2.9.sh)
```

Для установки нужны **SECRET_KEY из панели** и её **публичный IPv4**.
Используйте ссылку с `main` выше: ссылка на конкретный коммит запускает закреплённую версию.

## 🧭 Меню

| Пункт | Действие |
|:---:|---|
| **1** | Установка новой ноды |
| **2** | Аудит без изменения настроек и дополнительных вопросов |
| **3** | Продолжение установки после сбоя скачивания или запуска |
| **0** | Выход |

Меню показывает состояние ноды, UFW, защиты SSH, Ping IPv4, Logrotate и BBR.
После установки — отчёт по **10 шагам** с результатами и причинами ошибок.

## ⚙️ Что настраивается

| Компонент | Результат |
|---|---|
| **Docker + Compose** | Установка и запуск RemnaNode |
| **UFW** | Включается до запуска ноды; разрешения TCP: **22, 80, 443**, **2222** — для IP панели |
| **Fail2Ban** | Защита SSH и автозапуск: **5 ошибок за 10 минут → бан на 24 часа** |
| **Ping IPv4** | Блокировка входящих echo-request |
| **Logrotate** | Ротация файлов `/var/log/remnanode/*.log` |
| **BBR + fq** | Последняя настройка перед итоговой проверкой; сохранение для загрузки системы |

Аудит сам определяет IP панели по правилу UFW для **2222/TCP** и показывает краткую сводку портов. Если адрес не найден или их несколько — выводит предупреждение. UDP-сокеты `rw-core` отображаются одним счётчиком.

> **На заметку:** запись логов Xray включается в профиле панели. BBR требует поддержки ядром; блокировка ICMP может мешать диагностике и PMTU Discovery.

<sub>Цвета меню включаются автоматически в терминале. Для отключения задайте <code>NO_COLOR=1</code>.</sub>
