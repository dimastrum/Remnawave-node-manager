# Remnawave Node Manager

Автоматизированный Bash-установщик и аудитор RemnaNode для **Ubuntu 24.04 LTS**.

**Версия:** v0.2.9 (Beta)

### 🚀 Возможности

- Установка Docker, Docker Compose и RemnaNode.
- Подключение ноды к панели Remnawave.
- Настройка UFW, ICMP и Logrotate.
- Установка Fail2Ban и включение защиты SSH с автозапуском.
- Проверка состояния ноды и подключений.

### 📦 Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/dimastrum/Remnawave-node-manager/main/install-v0.2.9.sh)
```

### ⚙️ Меню

При запуске меню показывает состояние ноды, UFW, защиты SSH, входящего Ping (IPv4) и настройки Logrotate. Ping отображается как «Разрешён», «Запрещён» или «Не определён» по стандартным применённым правилам UFW; это не проверка доступности снаружи. Logrotate — «Настроен», «Не настроен», «Не установлен» или «Ошибка конфигурации». Статусы подсвечиваются в терминале; переменная `NO_COLOR` отключает цвета. Просмотр меню не меняет настройки сервера.

Установка и восстановление завершаются единым отчётом по девяти шагам: `✓` — выполнено, `✗` — ошибка, `·` — не выполнено. При сбое отчёт показывает причину и оставшиеся шаги. При восстановлении обновление Ubuntu отмечается как не выполнявшееся. Успешный отчёт также показывает Ping IPv4, API-порт и параметры защиты SSH.

**1** — Установить новую RemnaNode  
**2** — Проверить существующую ноду (без изменений)  
**3** — Завершить незавершённую установку

Для установки потребуются **SECRET_KEY** из Remnawave и публичный **IPv4 панели**.

После выбора пункта **1** скрипт сразу запрашивает SECRET_KEY и IP панели. Перед запуском RemnaNode он включает UFW: разрешает TCP-порты 22, 80 и 443, а доступ к API на TCP-порту 2222 разрешает от указанного IP панели. Соединение с панелью проверяется после применения firewall. При ошибке проверки нода остаётся запущенной с уже включённым UFW. Пункт **3** также проверяет соединение после применения настроек безопасности.

Пункт **3** использует существующий Compose-файл без повторного ввода SECRET_KEY и запрашивает IP панели. После настройки UFW он запускает Docker, при необходимости повторяет скачивание отсутствующего образа и создаёт или запускает остановленный контейнер. Уже работающая нода не перезапускается; имеющийся образ не обновляется. Если Compose-файла ещё нет, используйте пункт **1**. Контейнер с неожиданным каталогом логов или в состоянии паузы требует ручной проверки.

Fail2Ban защищает SSH на TCP-порту **22**: **5 неудачных попыток входа за 10 минут** приводят к блокировке доступа к SSH с этого IP на **24 часа**. Настройки записываются в `/etc/fail2ban/jail.d/99-remnanode-sshd.local`; существующий `jail.local` и настройки других служб сохраняются. Скрипт не создаёт правила Fail2Ban для Remnawave/Xray. Пункт **3** также включает эту защиту на ранее установленной ноде, а пункт **2** проверяет службу, автозапуск и jail `sshd` без изменений.
